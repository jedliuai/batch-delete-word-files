# 批量删除 Word 文档

这是一个本地桌面工具，使用 Python 标准库 `tkinter` 编写，不依赖 AI，也不需要额外安装第三方库。

程序用于递归扫描指定文件夹及其所有子文件夹中的 Word 文档，默认全部勾选。你可以手动取消不想删除的文件，随后点击“执行删除”完成批量删除。

## 功能说明

- 选择要扫描的目标文件夹
- 递归遍历所有子文件夹
- 自动识别 `.doc` 和 `.docx` 文件
- 扫描结果默认全部选中
- 支持手动取消勾选不需要删除的文件
- 点击“执行删除”后进行二次确认
- 删除完成后自动刷新列表
- 删除失败时显示失败原因

## 运行环境

- Windows
- Python 3

## 使用方法

在项目目录下执行：

```powershell
python main.py
```

如果你希望更方便地启动程序，也可以直接双击：

```text
启动程序.vbs
```

如果你想看到启动过程，也可以双击：

```text
start.bat
```

程序启动后按下面步骤操作：

1. 点击“选择文件夹”
2. 选择要扫描的目录
3. 点击“扫描 Word 文档”
4. 在列表中取消勾选不需要删除的文件
5. 点击“执行删除”
6. 在确认弹窗中确认删除

## 注意事项

- 当前版本会直接删除文件，不会移入回收站
- 删除后无法恢复，请在执行前仔细确认勾选内容
- 目前仅处理 `.doc` 和 `.docx` 两种格式
